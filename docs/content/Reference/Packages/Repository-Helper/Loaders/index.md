# Loaders
Loaders determine when awabbre packages are loaded by the repository helper (`awabbre-pkgs`).

## Loaders
| Loader | Summary |
| ------ | ------- |
| [Select](Select.md){data-preview} | Load a group or package directly by passing its path to `awabbre-pkgs select`. |
| [Lazy Bind](Lazy-Bind/index.md){data-preview} | Load packages on demand when one of their Base Commands is entered, using `awabbre-pkgs lazybind`. |
